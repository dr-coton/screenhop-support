ScreenHop 개인정보 처리방침

시행일: 2026년 11월 15일 · 버전 1.0

Code Black Inc.(이하 “회사”)는 iPad 앱 ScreenHop과 Mac 도우미 ScreenHop Host(이하 “앱”)에서 이용자의 개인정보를 다음과 같이 처리합니다.

1. 수집하는 개인정보: 없음

  • 앱은 개인정보를 수집하지 않으며, 회사 서버로 어떤 정보도 보내지 않습니다. 계정·회원가입이 없고, 회사가 운영하는 중계 서버도 없습니다.
  • 광고, 분석, 추적 SDK를 쓰지 않습니다. 앱 추적 투명성(ATT) 요청도 하지 않습니다.
  • Mac 화면 내용, 키보드·마우스·터치 입력, 클립보드, 소리, SSH 터미널 내용은 이용자의 iPad와 이용자의 Mac(또는 이용자가 지정한 SSH 서버) 사이에서만 암호화되어 오갑니다. 회사 서버로 수집하지 않으며, 세션 내용을 파일 등으로 영구 기록하지 않습니다(화면 표시를 위한 기기 메모리, 이용자가 직접 복사·붙여넣기한 내용은 예외).

2. 기기 안에만 저장되는 정보

항목목적위치
페어링한 Mac 이름·식별자, 직접 추가한 주소연결 목록 표시, 자동 재연결iPad 앱 데이터
기기 신원 키, 페어링한 Mac의 공개 키암호화 연결, 다른 컴퓨터의 위장 방지iPad Keychain(이 기기에만, iCloud 동기화 안 함)
SSH 호스트 정보(이름·주소·포트·사용자)터미널 연결iPad 앱 데이터

이 정보는 회사로 전송되지 않습니다. 앱을 삭제하면 앱 데이터가 지워집니다(Keychain 항목은 iPadOS 정책에 따라 남을 수 있으며, 페어링한 Mac의 신뢰 키는 설정 › 페어링한 Mac에서 잊기로, SSH 비밀번호는 호스트 삭제로, SSH 개인 키는 터미널 › 키 관리에서 삭제로 지울 수 있습니다).

3. 로컬 네트워크

같은 Wi-Fi의 Mac(및 SSH 기기)을 찾기 위해 iPadOS 로컬 네트워크 권한을 요청합니다. 찾은 기기 정보는 기기 안에서 목록 표시에만 씁니다.

4. 아동

앱은 아동을 대상으로 하지 않으며 아동의 정보를 수집하지 않습니다.

5. 문의

회사는 이용자를 식별할 수 있는 정보를 보관하지 않으므로 열람·삭제 요청 대상 정보가 회사에 없습니다.

문의: support@codeblack.co.kr · 지원: https://dr-coton.com/screenhop-support/

6. 변경

향후 광고 등 수집이 생기는 기능을 추가하면 앱 업데이트 전에 이 방침을 고치고 앱 안에서 알립니다.
