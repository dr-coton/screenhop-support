ScreenHop Host for Mac

iPad의 ScreenHop 앱으로 이 Mac을 쓰기 위한 무료 도우미입니다. 메뉴 막대에서 실행되며 개인정보를 수집하지 않습니다.

요구 사항

  • macOS 14 이상 (Apple Silicon·Intel 모두 지원), 사용자가 로그인한 상태
  • iPad에 ScreenHop 앱 설치 (App Store 링크는 출시 후 안내)
  • 같은 Wi-Fi. 밖에서는 Tailscale 같은 VPN을 직접 설정하고 iPad에서 Mac 주소를 직접 입력할 수 있습니다. USB 케이블 연결은 지원하지 않습니다.

설치 3단계

  1. 내려받은 ScreenHop-Host-버전.dmg를 엽니다.
  2. ScreenHop Host를 응용 프로그램 폴더로 끌어다 놓습니다.
  3. 응용 프로그램에서 ScreenHop Host를 실행하고, 안내에 따라 화면 기록과 손쉬운 사용을 허용합니다. 허용한 뒤 macOS가 앱을 다시 열라고 할 수 있습니다.

ScreenHop Host는 메뉴 막대에서 실행됩니다(Dock에 창이 뜨지 않을 수 있어요). 메뉴에서 ‘로그인 시 열기’를 켜 두면 Mac을 켤 때마다 자동으로 준비됩니다.

시스템 설정 › 개인정보 보호 및 보안에서 언제든 켜고 끌 수 있습니다.

처음 연결

  1. 같은 Wi-Fi에서 iPad의 ScreenHop을 열고 목록의 Mac을 누릅니다.
  2. iPad와 Mac 양쪽에 같은 6자리 코드가 보이는지 확인합니다.
  3. Mac 메뉴 막대에서 [허용]을 누릅니다. 이후에는 자동으로 연결됩니다.

Mac이 잠겨 있으면 Mac에서 직접 잠금을 풀어야 합니다. 안 풀리거나 연결이 안 되면 문제 해결을 보세요.

개인정보

화면·키 입력·클립보드는 암호화되어 로컬 네트워크로, 페어링된 iPad에만 전송됩니다. 개발사 서버로 보내는 것이 없고, 분석·광고 SDK도 없습니다. 개인정보 처리방침

지우는 방법

  1. 삭제 전에 메뉴 막대의 ScreenHop Host 메뉴 › 페어링된 iPad에서 iPad를 [페어링 해제]합니다(페어링 키가 지워지며, 그 iPad는 다시 페어링해야 합니다).
  2. 메뉴 막대에서 ScreenHop Host 종료를 누릅니다.
  3. 응용 프로그램 폴더에서 ScreenHop Host를 휴지통으로 옮깁니다.
  4. 시스템 설정 › 개인정보 보호 및 보안 › 화면 기록, 손쉬운 사용에서 ScreenHop Host 항목을 끄거나 제거합니다.
